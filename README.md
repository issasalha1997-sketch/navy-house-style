# Navy house style

A house style for documents, spreadsheets (Excel and Google Sheets), slides, figures and HTML explainer pages: Tahoma, calm spacing, plain English, no grey; navy #243168 for documents, sheets and pages, a calm green (#00684A) for slides.

This folder is a skill. `SKILL.md` is the entry point; `references/` holds the detailed rules for each kind of work (including `slides.md` for decks and banners); `assets/` holds a tested HTML template, an Excel (openpyxl) starter, a Google Sheets Apps Script starter with a dialog template, a PowerPoint kit with a demo deck and example renders (`assets/slides/`), the palette, and the official MongoDB logo files.

**Install:** copy this folder, named `navy-house-style`, into your skills folder, or upload `navy-house-style.zip` (from the latest release on this page) where skills are uploaded. To update an earlier copy, replace the whole folder with the new one.
