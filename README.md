# Navy house style

A house style for documents, spreadsheets (Excel and Google Sheets), figures and HTML explainer pages: navy #243168 as the one colour, Tahoma, calm spacing, plain English, no grey.

This folder is a skill. `SKILL.md` is the entry point; `references/` holds the detailed rules for each kind of work; `assets/` holds a tested HTML template, an Excel (openpyxl) starter, a Google Sheets Apps Script starter with a dialog template, the palette, and the official MongoDB logo files.

**Install:** copy this folder, named `navy-house-style`, into your skills folder, or upload `navy-house-style.zip` (from the release on this page) where skills are uploaded.
