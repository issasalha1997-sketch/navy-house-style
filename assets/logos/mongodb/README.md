# MongoDB logo files

Unaltered copies of official files from MongoDB's press kit ("Logos - Digital", https://brandfolder.com/mongodb/press-kit, linked from https://www.mongodb.com/brand-resources), downloaded on 26 Oct 2026. Only the file names were changed; `manifest.json` lists each original name and its SHA-256. Only the three versions that suit this style are included; the kit's Spring Green and Chartreuse versions are not (1.6:1 and 1.2:1 contrast on white, loud on navy).

| Files | Colour | With this style |
|---|---|---|
| `mongodb-logo-slate.svg` / `.png` | Slate #001E2B | The default: on white (contrast 17.2:1) |
| `mongodb-logo-evergreen.svg` / `.png` | Evergreen #023430 | On white, when a touch of the brand's green is wanted (13.7:1) |
| `mongodb-logo-off-white.svg` / `.png` | Off-white #FDFFF5 | On a navy band (12.1:1 on #243168) |
| `mongodb-leaf-slate`, `-evergreen`, `-off-white` (`.svg` / `.png`) | the same three colours | The leaf alone: only where the full logo is already shown, or the audience clearly knows it |

PNG files: full logo 4808 x 1228 px, leaf 530 x 1136 px, transparent backgrounds. SVG files: one colour each, so they stay sharp at any size. Word needs the PNG.

MongoDB's rules (brand page and Trademark Standards for Use):

- Do not edit, change, distort, recolour or reconfigure the marks, including the leaf.
- Use the colour version with the best contrast against its background; show the logo once, in a prominent place; never use the logo or the leaf as part of an illustration.
- Material not made by MongoDB: use the marks only to identify MongoDB's products and services; nothing may suggest MongoDB's sponsorship, endorsement or affiliation; your own name and logo stay more prominent than MongoDB's.
